# Prompts

Version-controlled prompt specifications for image and Flow video generation.

Naming convention:
- image: `IMG_<asset-id>_v###.md`
- video: `VID_<shot-id>_v###.md`

Every production prompt should record:
- goal
- locked references
- prompt text
- negative / must-not-drift rules
- model/mode when relevant
- result/QC link or asset ID
